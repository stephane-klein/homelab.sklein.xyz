# Runbooks

Operational procedures for the homelab. Runbooks are **living documents**:
stable filenames (no date), and an `Execution history` table at the bottom
recording when each run happened. Git history tracks changes to the procedure
itself.

- [enable-secrets-encryption.md](enable-secrets-encryption.md) — enable at-rest encryption of k3s Secrets on an existing cluster

See also: [../ops-log.md](../ops-log.md) for the one-off actions log.
